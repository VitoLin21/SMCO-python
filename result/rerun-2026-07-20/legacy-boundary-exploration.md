# 老反向结果 — 算法边界探索能力对比（论文素材）

- **日期**：2026-07-25
- **数据源**：`result/highdim-full-comparison-2026-06-04/all_results.csv`（老 6/04 基准，方向反，18928 rows，fopt 全正）
- **用途**：方向 bug 的反向结果（最大化 raw）重新解读为**算法全局探索 / 找 raw 极大（推边界）能力**的对比，作为论文副产物分析

---

## 1. 背景：反向 = 最大化 raw

老基准脚本对 `sense=="min"` 双重取负（`f=+raw`），SMCO 及所有对比算法实际**最大化 raw**（把 x 推向使 raw 最大的边界）。fopt = +raw（正值，边界值）。

**重新解读**：这等价于让算法求解 "max raw" 问题。raw 的极大值对最小化函数（真解 raw=0）在边界附近。因此老结果体现**算法找 raw 极大（推边界）的能力 = 全局探索 / 逃避局部最优 / 探索极端值的能力**。

`raw_max = fopt_old`（正边界值）。**越大 = 推边界越彻底 = 全局探索越强**。

## 2. 各算法推边界能力（raw_max 中位数，越大越强）

| 算法 | raw_max 中位（全维度） | 探索强度 |
|---|---|---|
| BOBYQA / GenSA / SA / PSO | 9001 | 最强（推到边界）|
| SMCO 系列（6 变体）| 8200–8754 | 强（稳定达边界）|
| GA | 7935 | 中 |
| optimLBFGS | 5957 | 中（凸问题爬山）|
| DEoptim | 4765 | 较弱 |
| GD / SignGD / ADAM / optimNM / SPSA | 3565–4500 | 最弱（陷局部，爬不到边界）|

**能力谱系**：全局退火/无梯度（GenSA/SA/PSO/BOBYQA）> SMCO 系列 > GA > 梯度类（GD/ADAM/SPSA/NM）。

梯度类（GD/ADAM/SPSA/NM）推边界最弱——它们沿梯度爬，易陷局部极大，无法到达全局边界极大。全局算法（GenSA 退火）探索彻底，达边界。

**关键发现**：
- **GenSA 推边界最强**（5000D 201766，远超其他）——广义模拟退火全局探索最彻底，找到最极端的 raw 极大。
- **SMCO 系列 / SA / PSO 稳定达边界极大**（5000D ~142500–145000）——一致达到 Rastrigin 边界极大（~142000）。
- **DEoptim / GA 推边界弱**（5000D ~95000）——差分进化/遗传算法全局搜索较弱，未达边界极大。
- 1000D GenSA/SA=40353（超 Rastrigin 边界 ~29000），可能在 Rosenbrock 等函数找到更大 raw。

Zakharov/Rosenbrock 边界 raw 巨大——这些函数的"极大值"（边界）远大于真解（0），推边界能力差异在这些函数上最显著。

## 5. 论文价值与解读

**可作为论文的副产物分析**：算法在"raw 极大化"（探索极端值）任务上的能力谱系：
1. **GenSA 全局探索最强**——模拟退火彻底探索，找到最极端 raw 极大（高维 201766）。
2. **SMCO 系列稳定探索**——一致达边界极大（~142500），探索能力可靠。
3. **DEoptim/GA 全局搜索弱**——未达边界极大。
4. **梯度类探索最弱**——陷局部极大，爬不到全局边界。

这反映算法的**全局搜索强度**（逃避局部最优、探索边界的能力），是算法特性的一个维度。

## 6. 局限（必须声明）

1. **边界 raw 是 trivial 极端值**：对 min 函数，raw 极大在边界（x→bounds），是平凡的。"推边界能力"≠ 标准"求极大值能力"（标准极大值任务有内部结构，非边界）。
2. **非原问题目标**：这些函数设计为最小化（真解 raw=0），"极大值"（边界）无数学意义，只是 bounds 副产物。
3. **不等同正确实验**：方向修正后的 min 实验（接近真解）才是主结论；本分析只是方法论副产物。
4. **max 函数（无 bug）**：`sense="max"` 函数方向本就正确，老结果有效——那些才是算法真实极大值能力的体现。

## 7. 结论

老反向结果（最大化 raw）可重新解读为**算法全局探索 / 推边界能力对比**：GenSA 最强 > SMCO 系列 ≈ SA/PSO > DEoptim/GA > 梯度类。作为论文副产物（算法探索能力谱系）有部分价值，但**不进入主结论**，且必须声明其 trivial 边界性质。
